
# OceanCloud Contributor Application Guide

Welcome to the OceanCloud international contributor programme.

This guide explains how interested developers can introduce themselves and begin the application process.

## 1. Who can apply?

OceanCloud welcomes applicants from all countries.

We are interested in:

- Junior developers.
- Experienced software engineers.
- Cloud and infrastructure engineers.
- Database and networking specialists.
- Defensive cybersecurity professionals.
- Designers and technical writers.
- Technology professionals with relevant experience.

## 2. Available contribution areas

### Backend Engineering
Node.js, TypeScript, Fastify, APIs, authentication and service architecture.

### Frontend Engineering
Web applications, user interfaces, accessibility and frontend architecture.

### Database Engineering
PostgreSQL, database design, migrations, performance and data integrity.

### Cloud and DevOps
Infrastructure, deployment automation, observability and reliability.

### Networking
DNS, CDN, routing, network architecture and connectivity.

### Defensive Cybersecurity
Security reviews, vulnerability assessment, monitoring and incident response.

### Software Quality
Automated testing, integration testing, code review and quality assurance.

### Product and Documentation
Product planning, technical documentation and user experience.

## 3. Application process

1. Read the OceanCloud README.
2. Read CONTRIBUTING.md.
3. Read CODE_OF_CONDUCT.md.
4. Introduce yourself through GitHub Discussions or the contributor introduction issue template.
5. Provide your public GitHub profile and examples of your work.
6. Wait for the application review.
7. If shortlisted, participate in a private conversation.
8. If approved, discuss a small and clearly defined initial contribution.

## 4. Screening process

OceanCloud may review:

- Public GitHub activity.
- Previous projects and code quality.
- Technical experience.
- References, where available.
- Communication and professionalism.
- Understanding of the project's current financial position.
- Willingness to respect security and confidentiality rules.

No single factor guarantees acceptance.

## 5. Voluntary participation

OceanCloud is currently self-funded.

There are no guaranteed salaries, payments, employment positions or future equity arrangements.

Applicants must freely decide whether they are willing to volunteer under these conditions.

Any future compensation or equity opportunity requires separate discussions and written agreements.

## 6. Security and access

Private engineering access is granted only after approval and completion of applicable agreements.

Applicants must not request passwords, access tokens or unrestricted administrator access.

All code contributions are subject to review.

## 7. Communication

Initial communication takes place through GitHub.

Private WhatsApp communication may be offered after screening.

Do not post personal telephone numbers or sensitive information publicly.

## 8. Application outcome

Applicants may be:

- Accepted for an initial contribution.
- Asked for additional information.
- Invited to a private discussion.
- Placed on hold.
- Declined.

OceanCloud aims to communicate decisions respectfully.

## 9. Final message

We value honesty, technical quality, responsibility and collaboration.

Thank you for your interest in building OceanCloud.
